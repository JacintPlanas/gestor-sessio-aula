# Gestor de sessió d'aula

Eina web per conduir una sessió d'aula de 55 minuts: les fases de la sessió amb el temps que queda, l'horari del centre i el timbre, avisos suaus, un temporitzador ràpid, la vista per projectar a l'alumnat (amb la diapositiva de la fase o sense) i un registre de cada sessió.

**Obre-la:** `https://<el-teu-usuari>.github.io/gestor-sessio-aula/`

## On es desen les dades

Tot es desa **només al navegador on s'obre** (plans, registres i diapositives). No s'envia res enlloc i **no es guarda cap dada de l'alumnat**.
Per passar-ho a un altre ordinador, o per tenir-ne una còpia: a «Planifica», **«Desa una còpia»** i, a l'altre ordinador, **«Recupera una còpia»**.
